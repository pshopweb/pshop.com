Mobile Account Redesign

Account button, account sheet aur profile page — phone ke liye dobara design

Problem kya thi

Phone par login karne ke baad Account button dabane par jo dropdown khulta tha wo desktop wala hi tha — chhota, screen ke kinare se chipka hua, aur uske andar ke links itne patle the ke ungli se tap karna mushkil tha. Profile page bhi desktop layout ko hi sikod kar dikhata tha.

Testing me ek asli bug bhi mila: profile/orders/settings jaise saare account pages phone par horizontally scroll ho rahe the — content viewport se bahar nikal jaata tha.

1. Naya mobile Account Sheet

Ab phone (≤767px) par Account button dropdown ki jagah ek bottom sheet kholta hai. Desktop par kuch nahi badla — wahan purana dropdown hi chalta hai.

HissaKya hai
Gradient headerBada avatar (naam ke initials se bana), poora naam, email aur role chip
Do CTA buttonsView profile aur Edit — dono 44px se bade
6 tilesOrders, Wishlist, Cart, Addresses, Alerts, Messages — live count badges ke saath
5 rowsTrack order, Compare, Coupons, Settings, Help centre

LogoutAlag red button, galti se dabne ka chance kam

Band karne ke 4 tarike

  • Upar wale × button se
  • Peeche wale overlay par tap karke
  • Neeche swipe karke (90px se zyada kheenchne par band)
  • Keyboard par Escape se

Bottom-nav ka Account tab

Pehle wo seedha profile.html khol deta tha. Ab phone par wahi sheet kholta hai — ek tap me saare account shortcuts saamne. Desktop par (ya agar header abhi load nahi hua) purana behaviour hi rehta hai, yaani link normally chalta hai.


// footer.js
mount.querySelector('[data-open-account-sheet]')?.addEventListener('click', e => {
  if (!window.matchMedia('(max-width:767px)').matches) return;
  if (typeof window.__pshopAccountSheet !== 'function') return;
  e.preventDefault();
  window.__pshopAccountSheet(true);
});

3. Asli bug — horizontal overflow

CSS grid ke children ka default min-width auto hota hai. Iska matlab child apne content se chhota ho hi nahi sakta. .shell-account ke andar .account-nav horizontally scroll karti hai, to uska content ~1076px chauda tha — aur poora page utna hi chauda ho gaya.


Mobile viewport : 390px
document.scrollWidth : 1088px    ← 698px extra!

Har account page affected tha — profile, orders, settings, address, edit-profile, notifications. Right side ka content screen se bahar chala jaata tha.

Fix


/* grid.css */
.shell-account > * { min-width: 0; }
.shell > *         { min-width: 0; }

Do lines, saara overflow khatam. Verify kiya gaya:

ViewportPehleAb
Mobile 390px1088px (overflow)390px ✅
Tablet 768pxok768px ✅
Desktop 1440pxok1440px ✅
