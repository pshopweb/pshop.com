Welcome to PShop

Complete e-commerce website — HTML, CSS, JavaScript aur Google Apps Script. Neeche 3 step me shuru karein.

⚠️
Aap file:// se khol rahe hain — website kaam nahi karegi

Modern browsers file:// par JavaScript modules block kar dete hain (security ki wajah se). Ye har modern website ke saath hota hai, PShop ki galti nahi. Neeche STEP 1 follow karein — 30 second ka kaam hai.

1

Local server chalayein

Website folder me terminal / command prompt kholein aur ye command chalayein:

python3 -m http.server 8000

Python na ho to Node se:

npx serve .

Phir browser me kholein: http://localhost:8000

Ya VS Code me Live Server extension install karke index.html par right-click → "Open with Live Server".

2

Google Sheet backend jodein (optional)

Backend ke bina bhi website chalti hai — demo data par. Asli data chahiye to:
