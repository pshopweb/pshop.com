Connection ab bahut better hai

Pehle kya problem thi

Ek bhi request fail hone par backend ko 60 second ke liye "dead" maan liya jata tha. Network ka ek chhota glitch bhi poori site ko demo data par daal deta tha — aur user ko pata bhi nahi chalta tha.

Ab kya hota hai

FeatureDetail
Auto retryFail hone par 3 koshish — 400ms, 800ms gap (exponential backoff)
Smart retrySirf network errors retry hote hain. Galat deployment jaise errors turant report ho jate hain
Request cacheProducts 60s, categories 5 min cache. Browsing me bar-bar call nahi jati
DedupeEk hi request do jagah se aaye to ek hi network call jati hai
Auto recoveryBackend down ho to background me check karta rehta hai (15s → 30s → 60s)
Offline detectInternet jaane par turant pata chal jata hai
Better errorsHTML response aaye to seedha batata hai: "deployment access Anyone karein"

User ko ab saaf dikhta hai

Pehle backend down hone par chup-chaap demo data dikhne lagta tha — user ko lagta tha website hi kharab hai. Ab neeche ek bar aati hai:

Server se connect nahi ho pa rahe
Abhi demo data dikha rahe hain. Background me dobara koshish jaari hai. [Retry]

Internet jaane par laal bar, backend down par peela. Wapas connect hone par apne aap chhup jati hai aur "Connection wapas aa gaya" dikhata hai.

Kaise test kiya

Sirf code likhkar nahi chhoda — asli browser me backend block karke, internet band karke test kiya. 10/10 pass:

  • Backend live → koi bar nahi dikhti
  • Backend block → products phir bhi dikhe (fallback), peeli bar aayi
  • Internet band → laal bar, sahi message
  • Wapas online → bar apne aap chhup gayi

Design polish

Ek naya layer add kiya — assets/css/base/polish.css. Ye sabse aakhir me load hota hai, isliye sirf visual refinement karta hai, layout nahi todta.

Shadows — do layer

Pehle ek flat shadow thi. Ab har shadow me do layers hain — ek tight (definition) aur ek soft spread (depth). Isse cards sach me "float" karte lagte hain.

--sh-md: 0 2px 4px rgba(15,23,42,.04),
         0 12px 24px -6px rgba(15,23,42,.10);

Spring animations

Linear easing ki jagah spring curve — natural bounce feel:

--ease-spring: cubic-bezier(.34,1.56,.64,1);

Typography

  • Bade headings par tighter tracking (-.025em) — premium feel
  • Prices me tabular-nums — numbers align rehte hain

Accessibility

  • Keyboard users ko clear focus ring, mouse users ko nahi
  • prefers-reduced-motion respect — motion sensitivity wale users ke liye saare animations band
  • Print styles — invoice print karne par UI chrome hat jata hai

Ek zaroori baat

Website file:// se nahi chalti — browser JavaScript modules block kar deta hai (security). Ye har modern site ke saath hota hai.

Local server chalayein: python3 -m http.server 8000
Phir kholein: http://localhost:8000

START-HERE.html kholne par ye warning apne aap dikhti hai, saath me exact command bhi.
